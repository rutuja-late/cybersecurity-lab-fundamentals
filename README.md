# Cybersecurity Lab Setup & Network Security Fundamentals

A hands-on lab project covering foundational cybersecurity concepts, Linux security fundamentals, cryptography, and network security tool familiarization, built using a Kali Linux + Metasploitable2 lab environment.

## Lab Environment
- **Attacker Machine:** Kali Linux (VMware) — `192.168.234.128`
- **Target Machine:** Metasploitable2 — `192.168.234.131`
- **Network:** Host-only/NAT adapter (isolated lab network)

## What's Covered
- **Cybersecurity Basics** — CIA Triad, common threat types, attack vectors
- **Linux Fundamentals** — file permissions, networking commands (`ifconfig`, `ping`, `netstat`, `traceroute`)
- **Networking Basics** — OSI model, TCP/IP suite, DNS/HTTP(S), IP addressing & NAT
- **Cryptography** — symmetric/asymmetric encryption, hashing, hands-on OpenSSL encrypt/decrypt + integrity check
- **Tool Familiarization** — Wireshark (packet capture), Nmap (port scanning), Burp Suite (web proxy), Netcat (network debugging)
